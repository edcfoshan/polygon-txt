# 修复 GDB 写入：补全 ArcPy 所需的系统文件

## 问题

EXE 生成的 GDB 只有 9 个文件（a00000001-04 的 gdbtable/gdbtablx + gdb marker），缺少 ArcPy 需要的：
- `timestamps` 文件（最关键）
- `a00000005` (GDB_ItemTypes) 系统表
- `.gdbindexes` 文件（每个表）
- `.horizon` 文件（空间表）
- `.atx` 文件（属性索引）
- `.spx` 文件（空间索引）

## 二进制格式（从参考 GDB 提取）

### timestamps (400 bytes)
```
Bytes 0-3:   ff ff ff ff (sentinel)
Bytes 4-7:   14 00 00 00 (version = 20)
Bytes 8-11:  ff ff ff ff (sentinel)
Bytes 12-15: 00 00 00 00 (flags)
Bytes 16-19: 32 00 00 00 (hash = 50)
Bytes 20-23: 02 00 00 00 (record_count = 2)
Bytes 24-27: 0e 00 00 00 (count = 14)
Bytes 28-31: 02 00 00 00 (count = 2)
Bytes 32-399: ff padding
```

### .horizon (32 bytes)
```
4 x (u32=2 + f64) = 32 bytes
Each entry: flag(2) + extent_value
xmin=-400, ymin=-90, xmax=400, ymax=90 (standard bounds)
```

### .gdbindexes (variable)
```
u32 num_indexes
For each index:
  u32 name_len_utf16
  UTF-16LE index_name
  u32 unknown (0x00000000)
  u32 field_count
  UTF-16LE field_name
  ... more fields
```

### .atx (4118 bytes)
```
B-tree attribute index structure (fixed size)
```

### .spx (variable, mostly zeros)
```
Spatial index grid (empty = all zeros)
```

## 实现计划

### 步骤 1：添加 timestamps 文件写入
在 `write_gdb_output()` 中添加 `write_timestamps()` 函数调用。

**文件**: `src-tauri/src/gdb.rs`
**位置**: 在 `write_gdb_items()` 调用之后（约 L1182）

### 步骤 2：添加 GDB_ItemTypes 系统表
添加 `write_gdb_item_types()` 函数，写入 a00000005.gdbtable + gdbtablx。

### 步骤 3：添加 .gdbindexes 文件
为每个表（a00000001-0005, a0000000b）添加 `.gdbindexes` 文件写入。

### 步骤 4：添加 .horizon 文件
为空间表（a00000004, a0000000b）添加 `.horizon` 文件。

### 步骤 5：添加 .atx 文件
为关键索引（TablesByName, CatItemsByPhysicalName 等）添加 `.atx` 文件。

### 步骤 6：添加 .spx 文件
为空间表添加空的 `.spx` 文件。

### 步骤 7：更新测试验证
更新 `debug_output_test.rs` 和 `verify_output.py` 以验证新文件。
