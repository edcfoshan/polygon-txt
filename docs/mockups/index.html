方案 A

折叠收纳式

保留三栏骨架，分组手风琴折叠 · 专业测绘风
  • 左栏三组折叠卡：导入 / 字段映射 / 输出选项
  • 中栏为「高级配置」（投影+表头）默认折叠
  • 改动最小，老用户零学习成本
  • 黄铜行业色系精致化，细边框工具感

方案 B

流程分区式

步骤导航（导入→映射→输出→高级）· 现代清爽风

  • 右侧预览常驻，配置流程一目了然
  • 低频配置收进步骤 4（默认折叠子卡）
  • 白底蓝强调、大圆角、留白（Linear 式克制）

工作台式

  • 顶部工具栏集中方向切换与转换按钮
