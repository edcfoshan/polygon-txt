# 极思G界址点互转工具 — UI 改动实现计划

## 校对后的完整流程

### 面→TXT 流程

1. **导入**：SHP（点击/拖拽，可多选）或 GDB（点击选择文件夹）
2. **GDB 图层选择**：导入 GDB 后，中央区域展示所有面图层，用户勾选要转换的图层
3. **配置**：字段映射自动匹配 + 表头自动识别 + 转换选项，用户可手动调整
4. **预览**：右侧实时预览 TXT 输出
5. **输出路径**：左栏最下方显示，默认在第一个数据文件所在目录下创建"临时数据"文件夹，用户可修改
6. **执行**：点击"开始转换"直接输出到该路径，不再弹出文件夹选择框

### TXT→面 流程

1. **导入**：TXT 文件（点击/拖拽，可多选）
2. **解析**：右侧立即显示解析日志（坐标系、地块列表、坐标点数）
3. **输出设置**：格式（**默认 SHP**）、文件组织（每个TXT一个图层/合并）、输出路径
4. **输出路径**：默认在第一个 TXT 文件所在目录下创建"临时数据"文件夹，用户可修改
5. **执行**：点击"导出"直接输出到该路径，不再弹出文件夹选择框

## 实现任务清单

### T1: 面→TXT 输出路径自动设置 + 直接导出

**涉及文件：**
- `index.html`：左栏添加输出路径输入框（只读）+ 浏览按钮
- `src/main.js`：导入第一个文件时自动创建"临时数据"文件夹路径；移除"开始转换"的弹窗逻辑
- `src-tauri/src/lib.rs`：`run_shp_to_txt` 命令接收 `output_dir` 参数（已有）

**改动要点：**
1. 面→TXT 左栏 `.mode-s` 区域最下方添加输出路径输入框（id=`out_dir_s`）
2. 导入 SHP/GDB 时，自动设置输出路径为数据文件所在目录 + `/临时数据/`
3. `runShpToTxt()` 函数中，直接使用 `out_dir_s` 的值作为输出目录，不再调用 `pick_output_dir`

### T2: TXT→面 输出路径自动设置 + 直接导出 + 默认 SHP

**涉及文件：**
- `index.html`：左栏 `.mode-t` 区域添加输出路径输入框（只读）；默认只勾选 SHP
- `src/main.js`：导入第一个 TXT 时自动创建"临时数据"文件夹路径；移除"导出"的弹窗逻辑
- `src-tauri/src/convert.rs`：`TxtToShpOptions.output_dir` 接收前端传来的路径

**改动要点：**
1. TXT→面 左栏 `.mode-t` 区域添加输出路径输入框（id=`out_dir`）
2. 导入 TXT 时，自动设置输出路径为第一个 TXT 文件所在目录 + `/临时数据/`
3. `of_gdb` 默认取消勾选（只勾选 `of_shp`）
4. `runTxtToShp()` 函数中，直接使用 `out_dir` 的值，不再调用 `pick_output_dir`

### T3: GDB 图层选择（中央区域展示）

**涉及文件：**
- `index.html`：中央预览区添加图层列表容器
- `src/main.js`：导入 GDB 后渲染图层列表（复选框 + 图层名 + 要素数）；转换时只处理勾选的图层
- `src-tauri/src/lib.rs`：`import_gdb` 返回 `layers` 列表（已有）；`run_shp_to_txt` 接收 `selected_layers` 参数
- `src-tauri/src/convert.rs`：`convert_shp_to_txt` 支持按图层名过滤

**改动要点：**
1. 中央 `.ctr-bd` 区域添加图层列表容器（id=`gdbLayers`）
2. `importGdb()` 成功后渲染图层列表：每个图层显示复选框 + 名称 + 要素数
3. 用户勾选/取消勾选图层时，更新预览
4. `runShpToTxt()` 传递 `selectedLayers` 参数给后端
5. 后端 `convert_shp_to_txt` 按图层名过滤，只转换勾选的图层

## 验证方案

1. **面→TXT 验证**：
   - 导入 SHP 文件，检查输出路径是否自动设为"临时数据"文件夹
   - 点击"开始转换"，验证直接转换到该路径（无弹窗）
   - 导入 GDB，检查中央区域是否显示图层列表
   - 勾选/取消图层，验证只转换勾选的图层

2. **TXT→面 验证**：
   - 导入 TXT 文件，检查输出路径是否自动设为"临时数据"文件夹
   - 检查输出格式是否默认只勾选 SHP
   - 点击"导出"，验证直接转换到该路径（无弹窗）
   - 修改输出路径后再次导出，验证路径生效

3. **集成测试**：
   ```
   cd src-tauri
   cargo test --test integration_test
   ```
