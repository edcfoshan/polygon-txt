# TXT→面 功能设计

## 概述

在 `prototype_v8.html` 中为 TXT→面（TXT to Polygon）模式设计完整的 UI 和交互逻辑。当前该模式只有骨架（文件导入 + 模拟转换），需要补充输出设置和增强解析日志。

## 设计约束（来自用户确认）

- **无字段映射** — TXT 内容固定且正确，不需要让用户选择属性字段
- **无预设方案** — 不与面→TXT 的预设系统耦合
- **坐标系** — 从 TXT [属性描述] 自动读取，缺失时默认 2000 国家大地坐标系
- **输出格式** — SHP + GDB（可分别勾选，默认全选）
- **文件组织** — 单选：每个 TXT 一个图层 / 合并输出
- **使用场景** — ArcGIS + QGIS
- **无图形预览** — 文本解析报告即可
- **版本号** — 标题栏"测镜"旁边加 V1.0

## 布局

**2 列布局**（与面→TXT 的中栏隐藏不同，TXT→面 直接使用 2 列）：

### 左栏（300px） — 文件导入 + 输出设置

**上半区：TXT 文件**
- 拖拽/点击导入 .txt 文件（可多选）
- 文件列表：文件名 + 大小 + 删除按钮
- 清空全部按钮

**下半区：输出设置**
- **输出格式**：SHP / GDB 复选框（默认全选）
- **文件组织**：单选按钮（每个TXT一个图层 / 合并输出）
- **输出目录**：只读输入框 + 浏览按钮

### 右栏（flex） — 解析结果 + 运行

**解析结果**
- 树形结构文本展示每个文件的：
  - 坐标系信息（自动识别的 CRS）
  - 地块列表（名称 / 用途 / 面积 / 坐标点数）
  - 汇总统计

**底部**
- 开始转换按钮
- 进度条 + 状态文字

## 交互逻辑

- 导入 TXT 后立即解析并更新解析日志
- `parseTxtPreview()` 增强输出：提取坐标系信息、显示树形结构
- `runTxt()` 保留模拟进度动画（实际转换需 ArcPy 或第三方库支持）
- 输出格式和文件组织选项通过新 DOM 元素管理（id 待定）
- 输出目录通过系统文件夹选择对话框设置

## 相对于面→TXT 的差异

| 项目 | 面→TXT | TXT→面 |
|------|--------|--------|
| 列布局 | 3列 | 2列 |
| 预设方案 | 有 | 无 |
| 字段映射 | 6个下拉框 | 无 |
| 转换选项 | 6个复选框 | 无 |
| 缓冲区 | 有 | 无 |
| 表头编辑 | 属性描述+项目信息 | 无 |
| 实时预览 | TXT预览 | 解析日志 |
| 输出设置 | 无 | 格式/组织/目录 |

## 待办改动清单

### v8 → v9（HTML/CSS/JS）

1. **标题栏**：brand-sub 加 "V1.0"
2. **CSS**：`.app[data-mode="t"]` 已有的 `.pnl-l{width:300px}` 维持不变
3. **左栏（mode-t）**：在文件列表下方新增"输出设置"区域
   - 输出格式：两个带样式的复选框（SHP / GDB），id 如 `#of_shp` `#of_gdb`
   - 文件组织：两个单选按钮，id 如 `#org_sep` `#org_merge`
   - 输出目录：只读 input + 浏览按钮，id 如 `#out_dir` `#out_btn`
4. **右栏解析日志**：`renderTxtParseLog()` 输出增强
   - 显示坐标系（从 TXT 解析或默认 CGCS2000）
   - 树形缩进展示地块信息
   - 汇总统计（文件数 / 地块数 / 坐标点总数）
5. **`runTxt()`**：验证输出目录是否选择，传参给模拟进度

### 样式

- 输出设置区域使用现有的 `.slabel`、`.fld`、`.btn` 样式保持一致
- 复选框/单选按钮使用 `accent-color: var(--ac)`
- 文件组织和格式选项用紧凑布局（flex row + gap）
- 不需要新增 CSS 变量或主题 token
