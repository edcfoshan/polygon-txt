# 禁用 VSCode Ctrl+P 快捷键

## 目标
取消 VSCode 中 `Ctrl+P`（快速打开文件）的默认快捷键。

## 方案
编辑用户级 keybindings 文件，添加一条禁用规则：

**文件**: `C:\Users\Administrator\AppData\Roaming\Code\User\keybindings.json`

在现有数组中追加：
```json
{
  "key": "ctrl+p",
  "command": "-workbench.action.quickOpen"
}
```

`-` 前缀表示移除该命令的默认绑定。

## 验证
重启 VSCode，按 `Ctrl+P`，应不再弹出快速打开面板。
