## 一、布局

880px 宽 × 自适应高，三栏：

- **左栏 198px**：输入设置（文件区 / 字段映射 / 输出目录）——锁定不可折叠
- **中栏 220px**：参数设置（坐标参数 / 转换选项 2 列 grid / 自定义表头）——锁定不可折叠，无滚动
- **右栏弹性**：表头预览 + 转换结果（**可折叠**）+ 底部运行栏

顶栏：品牌 mark + 预设下拉 + 主题切换按钮（浅色默认 → 暗色可切）。  
标签栏：2 tab + 3 预设 chip。

## 二、字段映射自动匹配（A）

- **导入前**：下拉框显示静态 option 列表，选中默认值（名称=DKMC，编号=DKBH，面积=自动，其余=默认）
- **导入后**：
  - 扫描文件字段名
  - 按优先级精确匹配：
    - 地块名称：DKMC → MC → NAME
    - 地块编号：DKBH → BH → ID
    - 面积：MJ → AREA → 自动
    - 用途：DKYT → YT → YONGTU → 默认
    - 图幅号：TFH → 默认
    - 地类：DLBM → DL → 默认
  - 匹配不到 → 默认
  - 下拉框 option 列表动态替换为文件实际字段名
- 用户可手动覆盖

## 三、自定义表头自动识别（B）

- 从 `.prj` 文件 WKT 解析空间参考
- 识别字段：坐标系、分带、投影、单位、带号
- 不可识别：精度（默认 `0.001`）、转换参数（默认 `,,,,,,`）
- **优先级**：文件识别 > 预设加载 > 手动修改
- 手动修改后不被自动覆盖
- SHP 先支持，GDB 后续

## 四、右栏实时预览（C）

- 完整 TXT 输出预览：`[属性描述]`（表头）+ `[地块坐标]`（地块名+编号+面积+用途+坐标串）
- 数据来源：表头←中栏，地块字段←左栏，坐标格式←左栏转换选项
- **限制**：前 3 地块 × 每块 ≤20 坐标点，末尾标注总数
- **刷新**：150ms debounce，只重算受影响段落
- **换文件**：清空重建，过渡期显示占位

## 五、关键 JS 技术点

- `.prj` WKT 解析：正则提取 `GEOGCS`, `PROJCS`, `PARAMETER["中央经线",...]` 等
- `.dbf` 字段名：解析 dBase III+ 文件头（前 32 字节每字段）
- 坐标转换预览：根据 checkbox 状态格式化坐标串
