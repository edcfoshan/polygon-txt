> 极思G界址点互转工具 — 面要素（SHP / GDB）与标准界址点 TXT 文件的双向转换

## 简介

**极思G界址点互转工具** 是一款面向测绘与国土行业的轻量级 GIS 桌面工具，实现面要素（SHP / GDB）与标准界址点 TXT 文件的双向转换。纯 Rust 实现，**无需安装 ArcPy / ArcGIS**。

## 主要功能

- **面 → TXT**：导入 SHP、GDB 面要素，输出标准界址点 TXT 文件
- **TXT → 面**：解析 TXT 文件，生成 SHP 矢量面数据
- 三种输出模式：一对一 / 按地块拆分 / 全合并
- 支持 **2000 国家大地坐标系、1980 西安、1954 北京、WGS84**
- 高斯克吕格投影 3°/6° 分带，带号自动提取
- **输出公里网坐标**：地理坐标系（经纬度）→ 高斯-克吕格投影平面坐标，自动加带号前缀
- 字段自动匹配，智能识别坐标系
- 自动面积计算（支持自动计算平方米/公顷）
- 浅色 / 暗色主题，自定义无边框窗口

## 下载安装

前往 [Releases](https://github.com/edcfoshan/polygon-txt/releases) 下载最新版本的 Windows 安装包，双击运行即可。

## 从源码构建

前置要求：[Node.js](https://nodejs.org/)、[Rust](https://www.rust-lang.org/)

```bash
npm install         # 安装前端依赖
npm run tauri dev   # 开发模式（热重载）
npm run tauri build # 生产构建（输出 NSIS 安装包）
```

## 技术栈

- **Tauri v2**（Rust 后端 + WebView 前端）
- **Rust**：shapefile / geonative-filegdb / chrono / **proj-core**（EPSG 标准投影）
- **前端**：原生 JS + Vite（单文件打包）

## 坐标系统

### PRJ 文件识别

软件自动读取与 SHP 同名的 `.prj` 文件，识别以下信息并填入表头：

| 表头字段 | 识别来源 | 示例值 |
|:--|:--|:--|
| 坐标系 | `GEOGCS` / `DATUM` | 2000国家大地坐标系 |
| 几度分带 | `Central_Meridian` 推算 | 3 |
| 投影类型 | `Projection` | 高斯克吕格 |
| 计量单位 | `UNIT` | 米 / 度 |
| 带号 | `Central_Meridian` / 3 | 37 |

### 公里网输出（坐标投影）

当 SHP 为地理坐标系（单位=度）时，勾选 **输出公里网** 后：

1. 使用 **proj-core**（EPSG 标准数据库）将经纬度投影为高斯-克吕格平面坐标
2. 中央经线由表头"带号"自动计算（带号×3）
3. 自动同步计量单位（度→米）
4. 东坐标加 **500km 假东偏 + 带号×1,000,000 前缀**
5. 最终格式：`J1,1,2587759.082,37688467.138`

投影精度与 ArcGIS Pro / QGIS 一致（< 1cm 与 EPSG 标准偏差）。
支持 CGCS2000、Xian1980、Beijing1954、WGS84 四种椭球体。

### 属性描述（自定义表头）

- 标准行（坐标系、几度分带、投影类型、计量单位、带号、精度、转换参数）不可删除
- 用户可通过"+ 添加属性行"新增自定义行，可删除
- 所有行支持拖拽排序、键值编辑

## 已知限制

- GDB 写入为最小化 OpenFileGDB 实现，ArcGIS Pro 兼容性有限（可回退 `ogr2ogr`）
- 部分政府格式 SHP 使用非标准格式（magic ≠ 9994），可能无法读取
